# AstroScope AI 천문대

AstroScope AI는 지능형 관측 계획 시스템이자 인터랙티브 플라네타륨입니다.

## 구현 완료

- 다국어 인터페이스
- 관측 위치 좌표 입력
- 현지 시간의 UTC 변환
- 율리우스일
- 수정 율리우스일
- 지방 겉보기 항성시
