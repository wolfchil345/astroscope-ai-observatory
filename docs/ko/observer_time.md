# 관측 위치와 천문 시간

이 모듈은 관측자의 현지 날짜와 시간을 천문학에서 사용하는 시간 값으로 변환합니다.

## 관측자 좌표

관측 위치는 다음 정보로 표현합니다.

- 위도
- 경도
- 해발 고도
- 시간대 식별자

동경은 양수이고 서경은 음수입니다.

## UTC

천문 계산을 수행하기 전에 현지 표준시를 협정 세계시로 변환합니다.

## 율리우스일

율리우스일은 천문학에서 사용하는 연속적인 날짜 계산 방식입니다.

## 수정 율리우스일

수정 율리우스일은 다음 식으로 계산합니다.

MJD = JD - 2400000.5

## 지방 겉보기 항성시

지방 겉보기 항성시는 어떤 적경이 관측지의 자오선을 통과하는지 나타냅니다.
