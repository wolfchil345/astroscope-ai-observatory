# เครื่องมือสำรวจระบบสุริยะ

โมดูลนี้คำนวณตำแหน่งปรากฏของวัตถุในระบบสุริยะตามตำแหน่งและเวลาของผู้สังเกตการณ์

## วัตถุที่รองรับ

- ดวงอาทิตย์
- ดวงจันทร์
- ดาวพุธ
- ดาวศุกร์
- ดาวอังคาร
- ดาวพฤหัสบดี
- ดาวเสาร์
- ดาวยูเรนัส
- ดาวเนปจูน

## ค่าที่คำนวณ

- ไรต์แอสเซนชันและเดคลิเนชันปรากฏ
- ระยะจากผู้สังเกตการณ์
- มุมเงยและมุมทิศ
- ทิศทาง
- สถานะการสังเกตการณ์
- ระยะเชิงมุมจากดวงอาทิตย์
- ระยะเชิงมุมจากดวงจันทร์
- สัดส่วนความสว่างโดยประมาณของดวงจันทร์

## เอเฟเมอริส

Mission 5 ใช้เอเฟเมอริสในตัวของ Astropy จึงไม่ต้องดาวน์โหลดเคอร์เนลเอเฟเมอริสภายนอก

## ความสว่างของดวงจันทร์

สัดส่วนความสว่างของดวงจันทร์ประมาณจากระยะเชิงมุมปรากฏระหว่างดวงอาทิตย์กับดวงจันทร์
