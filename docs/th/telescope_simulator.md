# เครื่องจำลองกล้องโทรทรรศน์และเลนส์ตา

เครื่องจำลองนี้คำนวณการทำงานร่วมกันของกล้องโทรทรรศน์ เลนส์ตา บาร์โลว์ และตัวลดโฟกัส

## ค่าที่คำนวณ

- อัตราส่วนโฟกัสดั้งเดิมและที่มีผล
- ทางยาวโฟกัสที่มีผล
- กำลังขยาย
- รูม่านตาออก
- สนามมองจริงโดยประมาณ
- ขีดจำกัดดอว์ส
- ขีดจำกัดเรย์ลี
- ช่วงกำลังขยายใช้งานโดยประมาณ

## การเปรียบเทียบเลนส์ตา

สามารถเปรียบเทียบเลนส์ตาที่มีอยู่โดยใช้กล้องและอุปกรณ์เสริมที่เลือก

## ภาพจำลองสนามมอง

เปรียบเทียบสนามมองวงกลมของกล้องกับขนาดเชิงมุมโดยประมาณของ:

- ดวงจันทร์
- ดาราจักรแอนดรอเมดา
- กระจุกดาวลูกไก่
- เนบิวลานายพราน

ขนาดเชิงมุมเป็นค่าประมาณเพื่อการศึกษา มลภาวะทางแสงอาจทำให้ส่วนรอบนอกที่จางมองไม่เห็นและวัตถุดูเล็กลง

## ความปลอดภัย

ห้ามสังเกตดวงอาทิตย์ผ่านกล้องโทรทรรศน์โดยไม่มีแผ่นกรองแสงอาทิตย์ด้านหน้าที่ได้รับการรับรอง

## ข้อจำกัด

ประสิทธิภาพจริงยังขึ้นอยู่กับบรรยากาศ คุณภาพระบบแสง การปรับแนว ความสว่างของวัตถุ สายตา และความมั่นคงของอุปกรณ์
