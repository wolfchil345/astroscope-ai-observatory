# พิกัดขอบฟ้าและการมองเห็น

โมดูลนี้แปลงไรต์แอสเซนชันและเดคลิเนชันแบบ ICRS เป็นพิกัดขอบฟ้าของผู้สังเกตการณ์

## มุมเงย

มุมเงยแสดงว่าวัตถุอยู่สูงหรือต่ำกว่าขอบฟ้าเท่าใด

- ขอบฟ้า: 0 องศา
- จุดเหนือศีรษะ: 90 องศา
- ใต้ขอบฟ้า: มุมเงยติดลบ

## มุมทิศ

มุมทิศวัดจากทิศเหนือไปทางทิศตะวันออก

- เหนือ: 0 องศา
- ตะวันออก: 90 องศา
- ใต้: 180 องศา
- ตะวันตก: 270 องศา

## การจัดประเภทการมองเห็น

วัตถุจะถูกจัดประเภทเป็น:

- สามารถสังเกตได้
- อยู่เหนือขอบฟ้าแต่มุมเงยต่ำ
- อยู่ใต้ขอบฟ้า

ผู้ใช้สามารถกำหนดมุมเงยต่ำสุดได้

## มวลอากาศ

ระบบจะแสดงค่ามวลอากาศโดยประมาณเมื่อมุมเงยอย่างน้อย 5 องศา

## การหักเหของบรรยากาศ

Mission 4 ใช้พิกัดขอบฟ้าเชิงเรขาคณิตโดยปิดการแก้ไขการหักเหของบรรยากาศ
