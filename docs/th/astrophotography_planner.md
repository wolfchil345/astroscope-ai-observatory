# เครื่องวางแผนเซนเซอร์และภาพโมเสกดาราศาสตร์

เครื่องมือนี้ประเมินการทำงานร่วมกันของกล้องโทรทรรศน์และกล้องถ่ายภาพดาราศาสตร์

## ค่าที่คำนวณ

- ทางยาวโฟกัสและอัตราส่วนโฟกัสที่มีผล
- ขนาดเซนเซอร์
- สเกลภาพต่อพิกเซล
- สนามท้องฟ้าแนวนอน แนวตั้ง และแนวทแยง
- การสุ่มตัวอย่างดิสก์ซีอิง
- การสุ่มตัวอย่างขีดจำกัดดอว์ส
- ช่วงสเกลภาพที่แนะนำ

## การประเมินการสุ่มตัวอย่าง

ประเมินจากค่าซีอิงของบรรยากาศที่เลือก:

- มากเกินไป
- เหมาะสม
- ไม่เพียงพอ
- ไม่เพียงพออย่างมาก

## การจัดกรอบวัตถุ

สามารถเปรียบเทียบดวงจันทร์ ดาราจักรแอนดรอเมดา กระจุกดาวลูกไก่ เนบิวลานายพราน เนบิวลากุหลาบ และเนบิวลากูน

ระบบคำนวณสัดส่วนเฟรม จำนวนแผงแนวนอนและแนวตั้ง จำนวนรวม และพื้นที่ครอบคลุม

## การหมุน

มุมหมุนเซนเซอร์แสดงในภาพ จำนวนแผงโมเสกยังคำนวณจากขนาดสนามมองก่อนหมุน

## ข้อจำกัด

ขนาดวัตถุเป็นค่าประมาณ การจัดกรอบจริงขึ้นอยู่กับมุมกล้อง ความบิดเบี้ยว การครอป การไกด์ dithering การซ้อนภาพ และขอบวัตถุที่จาง
