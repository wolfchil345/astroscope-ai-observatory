# สมุดบันทึกการสังเกตการณ์

บันทึกเซสชันการสังเกตด้วยตา การถ่ายภาพ หรือทั้งสองรูปแบบ

## ข้อมูลเซสชัน

จัดเก็บผู้สังเกต สถานที่ เวลาเริ่มและสิ้นสุด พิกัด ระดับความสูง ซีอิง ความโปร่งใส ปริมาณเมฆ อุปกรณ์ และบันทึกทั่วไป

## บันทึกวัตถุ

แต่ละวัตถุมีข้อมูล:

- รหัส ชื่อ และประเภท
- เวลาเริ่มและสิ้นสุด
- ผลการสังเกต
- ระดับคุณภาพ
- มุมเงย
- เวลาเปิดรับแสงและจำนวนเฟรม
- บันทึกเพิ่มเติม

## สรุป

คำนวณระยะเวลาเซสชัน จำนวนวัตถุ อัตราสำเร็จ คุณภาพเฉลี่ย เวลาสังเกตรวม อัตราเฟรมที่ใช้ได้ และเวลาเปิดรับแสงรวม

## นำเข้าและส่งออก

- ส่งออกและนำเข้าเซสชัน JSON
- ส่งออก CSV หนึ่งแถวต่อวัตถุ
- สร้างรายงาน Markdown

JSON เป็นรูปแบบเซสชันสมบูรณ์ที่นำกลับมาใช้ได้ ส่วน CSV เหมาะสำหรับการวิเคราะห์ตาราง
