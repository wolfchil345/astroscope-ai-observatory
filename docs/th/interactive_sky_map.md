# แผนที่ท้องฟ้าท้องถิ่นแบบโต้ตอบ

แผนที่นี้แสดงวัตถุท้องฟ้าที่อยู่เหนือขอบฟ้าของผู้สังเกตการณ์

## โครงสร้างแผนที่เชิงขั้ว

- จุดศูนย์กลางแทนจุดเหนือศีรษะ
- วงกลมด้านนอกแทนขอบฟ้า
- มุมทิศกำหนดตำแหน่งเชิงมุม
- ระยะจากจุดเหนือศีรษะกำหนดตำแหน่งเชิงรัศมี

พิกัดเชิงรัศมีคำนวณด้วยสูตร:

`ระยะเชิงรัศมี = 90 องศา - มุมเงย`

## ประเภทวัตถุ

- ดาวจากแค็ตตาล็อกและกาแล็กซีแอนดรอเมดา
- ดวงอาทิตย์ ดวงจันทร์ และดาวเคราะห์

## การโต้ตอบ

เมื่อเลื่อนเมาส์เหนือเครื่องหมาย ระบบจะแสดง:

- ชื่อวัตถุ
- มุมเงย
- มุมทิศ
- ทิศทาง
- สถานะการมองเห็น
