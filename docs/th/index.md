# หอดูดาว AstroScope AI

AstroScope AI คือระบบวางแผนการสังเกตการณ์อัจฉริยะและท้องฟ้าจำลองแบบโต้ตอบ

## ฟังก์ชันที่พัฒนาแล้ว

- อินเทอร์เฟซหลายภาษา
- การป้อนพิกัดผู้สังเกตการณ์
- การแปลงเวลาท้องถิ่นเป็น UTC
- วันจูเลียน
- วันจูเลียนดัดแปลง
- เวลาดาราคติปรากฏท้องถิ่น

## Mission 14: เครื่องมือสำรวจทรานซิตดาวเคราะห์นอกระบบ

Mission 14 เชื่อมต่อ AstroScope กับ NASA Exoplanet Archive

แดชบอร์ดประกอบด้วยตัวกรองแคตตาล็อก กราฟประชากรดาวเคราะห์ เครื่องมือตรวจสอบดาวเคราะห์ การส่งออก CSV การตรวจสอบ ADQL และเครื่องจำลองทรานซิตเพื่อการศึกษา

คำว่าผู้สมัครดาวเคราะห์หินเขตอบอุ่นเป็นเพียงผลการคัดกรองเบื้องต้น และไม่ได้ยืนยันว่าดาวเคราะห์นั้นสามารถอยู่อาศัยได้
