# หอดูดาว AstroScope AI

AstroScope AI คือระบบวางแผนการสังเกตการณ์อัจฉริยะและท้องฟ้าจำลองแบบโต้ตอบ

## ฟังก์ชันที่พัฒนาแล้ว

- อินเทอร์เฟซหลายภาษา
- การป้อนพิกัดผู้สังเกตการณ์
- การแปลงเวลาท้องถิ่นเป็น UTC
- วันจูเลียน
- วันจูเลียนดัดแปลง
- เวลาดาราคติปรากฏท้องถิ่น

## เอกสาร

- [ตำแหน่งผู้สังเกตการณ์และเวลาดาราศาสตร์](observer_time.md)

## เป้าหมายในอนาคต

- การคำนวณพิกัดท้องฟ้า
- การคำนวณการมองเห็นวัตถุท้องฟ้า
- แผนที่ดาวแบบโต้ตอบ
- การจำลองขอบเขตการมองเห็นของกล้องโทรทรรศน์
- การสำรวจแค็ตตาล็อกดาราศาสตร์
