# หอดูดาว AstroScope AI

AstroScope AI คือระบบวางแผนการสังเกตการณ์อัจฉริยะและท้องฟ้าจำลองแบบโต้ตอบ

## เป้าหมายเริ่มต้น

- คำนวณการมองเห็นวัตถุท้องฟ้า
- สร้างตารางการสังเกตการณ์
- แสดงแผนที่ท้องฟ้าแบบโต้ตอบ
- จำลองขอบเขตการมองเห็นของกล้องโทรทรรศน์
- สำรวจแค็ตตาล็อกดาราศาสตร์เชิงวิทยาศาสตร์
