# ตำแหน่งผู้สังเกตการณ์และเวลาดาราศาสตร์

โมดูลนี้แปลงวันและเวลาท้องถิ่นของผู้สังเกตการณ์เป็นค่าทางเวลาดาราศาสตร์

## พิกัดของผู้สังเกตการณ์

ตำแหน่งสังเกตการณ์ประกอบด้วยข้อมูลต่อไปนี้

- ละติจูด
- ลองจิจูด
- ความสูงจากระดับน้ำทะเล
- ตัวระบุเขตเวลา

ลองจิจูดตะวันออกเป็นค่าบวก และลองจิจูดตะวันตกเป็นค่าลบ

## UTC

เวลาท้องถิ่นจะถูกแปลงเป็นเวลาสากลเชิงพิกัดก่อนทำการคำนวณทางดาราศาสตร์

## วันจูเลียน

วันจูเลียนเป็นการนับวันอย่างต่อเนื่องที่ใช้ในงานดาราศาสตร์

## วันจูเลียนดัดแปลง

วันจูเลียนดัดแปลงคำนวณด้วยสมการต่อไปนี้

MJD = JD - 2400000.5

## เวลาดาราคติปรากฏท้องถิ่น

เวลาดาราคติปรากฏท้องถิ่นแสดงว่าไรต์แอสเซนชันใดกำลังผ่านเส้นเมริเดียนของผู้สังเกตการณ์
