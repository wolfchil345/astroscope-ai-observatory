- 観測天気スコアと結露リスク警告

- 夜間全体の観測タイムライン
- 時系列の観測対象自動スケジュール
- スコア変化のインタラクティブ図

- スマート観測対象ランキング

- インタラクティブな現地全天星図

- 多言語ホバー情報

- 太陽系天体の見かけの位置計算
- 太陽、月、8惑星のエクスプローラー

- 4言語対応Streamlitインターフェース

## Mission 14：NASA系外惑星トランジット・温和惑星エクスプローラー

AstroScopeはNASA Exoplanet Archiveから確認済み系外惑星のデータを取得し、インタラクティブな科学ダッシュボードとして表示できます。

### 主な機能

- 発見方法、トランジットの有無、距離、惑星半径、平衡温度による検索
- 半径と公転周期、質量と半径、温度と日射量の比較グラフ
- 軌道、惑星、恒星、トランジット推定値の詳細表示
- 教育用の台形トランジット光度曲線シミュレーション
- 温和な地球型惑星候補のスクリーニング
- 検索結果のCSV出力
- 生成されたADQLクエリの確認

### 科学上の注意

温和条件の判定は候補を絞り込むための簡易スクリーニングであり、生命居住可能性を証明するものではありません。トランジット確率、密度、気候関連の値には、単純化した計算またはアーカイブの報告値を使用します。トランジット・シミュレーターには周辺減光、恒星活動、大気効果、観測機器ノイズは含まれません。

### データソース

カタログデータはNASA Exoplanet ArchiveのTAPサービスを通じて、`pscomppars`テーブルから取得します。
