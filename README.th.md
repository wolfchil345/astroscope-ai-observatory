# หอดูดาว AstroScope AI 🔭

ระบบวางแผนการสังเกตการณ์อัจฉริยะและท้องฟ้าจำลองแบบโต้ตอบ

## ภาษาที่รองรับ

- อังกฤษ
- ญี่ปุ่น
- เกาหลี
- ไทย

## ฟังก์ชันที่พัฒนาแล้ว

- เครื่องสำรวจแค็ตตาล็อกดาว Gaia DR3
- แผนที่ท้องฟ้า แผนภาพสี และการเคลื่อนที่
- รายละเอียดแหล่งข้อมูลและส่งออก CSV

- สมุดบันทึกการสังเกตการณ์แบบมีโครงสร้าง
- สรุปเซสชันการสังเกตและถ่ายภาพ
- ส่งออก JSON, CSV และ Markdown

- เครื่องวางแผนเซนเซอร์และภาพโมเสกดาราศาสตร์
- การวิเคราะห์สเกลภาพและการสุ่มตัวอย่างซีอิง
- ภาพเซนเซอร์หมุนได้และรูปแบบโมเสก

- เครื่องจำลองกล้องโทรทรรศน์และเลนส์ตา
- การคำนวณบาร์โลว์และตัวลดโฟกัส
- ภาพจำลองสนามมองเชิงมุมแบบโต้ตอบ

- สภาพการสังเกตการณ์ที่คำนึงถึงสภาพอากาศ
- พยากรณ์เมฆ ฝน ลม และทัศนวิสัยรายชั่วโมง
- คะแนนสภาพอากาศและคำเตือนความเสี่ยงจากน้ำค้าง

- ไทม์ไลน์การสังเกตการณ์ตลอดทั้งคืน
- ตารางวัตถุอัตโนมัติตามลำดับเวลา
- แผนภูมิการเปลี่ยนแปลงคะแนนแบบโต้ตอบ

- การจัดอันดับวัตถุสังเกตการณ์อัจฉริยะ
- คะแนนคุณภาพ 100 คะแนนที่อธิบายได้
- ตัวกรองระยะจากดวงจันทร์และความมืด

- แผนที่ท้องฟ้าท้องถิ่นแบบขั้วที่โต้ตอบได้
- ชั้นข้อมูลวัตถุจากแค็ตตาล็อกและระบบสุริยะ
- ข้อมูลเมื่อเลื่อนเมาส์แบบหลายภาษา

- การคำนวณตำแหน่งปรากฏของระบบสุริยะ
- เครื่องมือสำรวจดวงอาทิตย์ ดวงจันทร์ และดาวเคราะห์ 8 ดวง
- ระยะจากดวงอาทิตย์และความสว่างของดวงจันทร์

- อินเทอร์เฟซ Streamlit 4 ภาษา
- ละติจูด ลองจิจูด และระดับความสูงของผู้สังเกตการณ์
- การแปลงเขตเวลา
- วันและเวลา UTC
- วันจูเลียนและวันจูเลียนดัดแปลง
- เวลาดาราคติปรากฏท้องถิ่น
- ไรต์แอสเซนชันและเดคลิเนชันแบบ ICRS
- การแปลงพิกัดกาแล็กซี
- เวกเตอร์ทิศทางท้องฟ้าแบบคาร์ทีเซียน
- มุมเงยและมุมทิศท้องถิ่น
- การจำแนกขอบฟ้าและความสามารถในการสังเกต
- ทิศทางและมวลอากาศโดยประมาณ

## Mission 14: เครื่องมือสำรวจทรานซิตและดาวเคราะห์เขตอบอุ่นของ NASA

AstroScope สามารถดึงข้อมูลดาวเคราะห์นอกระบบที่ได้รับการยืนยันจาก NASA Exoplanet Archive และแสดงผลเป็นแดชบอร์ดวิทยาศาสตร์แบบโต้ตอบได้

### ความสามารถหลัก

- กรองตามวิธีการค้นพบ การเกิดทรานซิต ระยะทาง รัศมี และอุณหภูมิสมดุล
- เปรียบเทียบประชากรดาวเคราะห์ด้วยกราฟรัศมี-คาบโคจร มวล-รัศมี และอุณหภูมิ-พลังงานจากดาวฤกษ์
- ตรวจสอบข้อมูลวงโคจร ดาวเคราะห์ ดาวฤกษ์ และค่าทรานซิตโดยประมาณ
- จำลองกราฟแสงทรานซิตแบบสี่เหลี่ยมคางหมูเพื่อการศึกษา
- คัดกรองผู้สมัครดาวเคราะห์หินในเขตอบอุ่น
- ส่งออกผลการค้นหาเป็น CSV
- ตรวจสอบคำสั่ง ADQL ที่ระบบสร้างขึ้น

### ข้อควรระวังทางวิทยาศาสตร์

การจำแนกเขตอบอุ่นเป็นเพียงเครื่องมือคัดกรอง ไม่ใช่หลักฐานว่าดาวเคราะห์สามารถอยู่อาศัยได้ ค่าความน่าจะเป็นของทรานซิต ความหนาแน่น และข้อมูลภูมิอากาศใช้การคำนวณแบบง่ายหรือค่าที่รายงานในคลังข้อมูล เครื่องจำลองไม่รวมผลมืดบริเวณขอบดาว กิจกรรมของดาวฤกษ์ ผลจากบรรยากาศ หรือสัญญาณรบกวนจากเครื่องมือ

### แหล่งข้อมูล

ข้อมูลแคตตาล็อกมาจากตาราง `pscomppars` ผ่านบริการ TAP ของ NASA Exoplanet Archive
