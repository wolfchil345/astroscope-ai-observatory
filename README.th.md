# หอดูดาว AstroScope AI 🔭

ระบบวางแผนการสังเกตการณ์อัจฉริยะและท้องฟ้าจำลองแบบโต้ตอบ

## ภาษาที่รองรับ

- อังกฤษ
- ญี่ปุ่น
- เกาหลี
- ไทย

## ฟังก์ชันที่พัฒนาแล้ว

- แผนที่ท้องฟ้าท้องถิ่นแบบขั้วที่โต้ตอบได้
- ชั้นข้อมูลวัตถุจากแค็ตตาล็อกและระบบสุริยะ
- ข้อมูลเมื่อเลื่อนเมาส์แบบหลายภาษา

- การคำนวณตำแหน่งปรากฏของระบบสุริยะ
- เครื่องมือสำรวจดวงอาทิตย์ ดวงจันทร์ และดาวเคราะห์ 8 ดวง
- ระยะจากดวงอาทิตย์และความสว่างของดวงจันทร์

- อินเทอร์เฟซ Streamlit 4 ภาษา
- ละติจูด ลองจิจูด และระดับความสูงของผู้สังเกตการณ์
- การแปลงเขตเวลา
- วันและเวลา UTC
- วันจูเลียนและวันจูเลียนดัดแปลง
- เวลาดาราคติปรากฏท้องถิ่น
- ไรต์แอสเซนชันและเดคลิเนชันแบบ ICRS
- การแปลงพิกัดกาแล็กซี
- เวกเตอร์ทิศทางท้องฟ้าแบบคาร์ทีเซียน
- มุมเงยและมุมทิศท้องถิ่น
- การจำแนกขอบฟ้าและความสามารถในการสังเกต
- ทิศทางและมวลอากาศโดยประมาณ

## การติดตั้ง

เรียกใช้ `python -m pip install -e ".[dev]"`

## การเปิดใช้งาน

เรียกใช้ `make run`

## การทดสอบ

เรียกใช้ `make checks`
